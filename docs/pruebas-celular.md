# Pruebas en celular antes de publicar

Hazlo una vez en iPhone (Safari) y una vez en Android (Chrome). Marca cada paso. Si algo falla, mándalo desde la misma app (Ajustes → Enviar comentario, con captura) o pásame una foto.

Link: https://seasonpay.vercel.app/hola

## 1. Primera vez (sin cuenta)
- [ ] La página de inicio carga y se ve bien (texto, 6 tarjetas, preguntas frecuentes).
- [ ] El botón "English" cambia todo a inglés y vuelve a español.
- [ ] "Empezar ahora" abre la bienvenida: visa, año de llegada, estado, empleador y aceptar la política.
- [ ] Al terminar llegas a Hoy.

## 2. Instalar
- [ ] iPhone: Safari → Compartir → "Agregar a inicio". El ícono aparece en la pantalla de inicio.
- [ ] Android: Chrome → ⋮ → "Instalar app" (o el botón "Instalar app" de la página).
- [ ] Abrir desde el ícono: se ve sin la barra del navegador.

## 3. Turnos y propinas
- [ ] Iniciar turno, esperar un minuto, terminarlo y poner propinas en efectivo y tarjeta.
- [ ] Cargar un turno a mano que termine después de medianoche.
- [ ] Semana: horas, overtime y la tarjeta del overtime de tu estado.

## 4. Sin señal
- [ ] Activar modo avión.
- [ ] Cerrar la app por completo y volver a abrirla desde el ícono: tiene que abrir.
- [ ] Registrar un turno y una boleta en modo avión.
- [ ] Quitar el modo avión: el ahorro trae el tipo de cambio y los comentarios pendientes se envían.

## 5. Boletas y Social Security
- [ ] Agregar una boleta con Social Security y Medicare retenidos.
- [ ] Aparece el aviso de Social Security y Medicare con el link al IRS.

## 6. Temporada
- [ ] Fechas límite: 1040-NR 2026 (15 abr 2027) y 2027 (15 abr 2028, marcada "Cae sábado").
- [ ] Botón "Recordármelo con notificaciones": acepta el permiso. En iPhone solo funciona con la app instalada.
- [ ] Checklist: la declaración estatal muestra el texto de tu estado con su fuente.
- [ ] Ahorro: agregar un movimiento y ver el monto en soles.
- [ ] Exportar resumen: se descarga el PDF y el CSV.
- [ ] Enviar plata a casa: cambiar de país y ver los proveedores; en Perú, agregar una cotización.

## 7. Cuenta (opcional)
- [ ] Ajustes → Crear cuenta o entrar → crear usuario y contraseña. Entra sin pedir correo.
- [ ] Ajustes muestra @tu_usuario y "Cambiar contraseña".
- [ ] Cerrar sesión, volver a entrar con el usuario y ver que los datos regresan.
- [ ] Con el usuario creado, pasárselo a Claude para hacerlo admin y abrir /admin.

## 8. Privacidad y borrar
- [ ] Ajustes → Política de privacidad se abre.
- [ ] Ajustes → Exportar mis datos descarga un archivo JSON.
- [ ] (En un celular de prueba) Ajustes → Borrar mi cuenta y mis datos: vuelve a la bienvenida, sin datos.

## 9. Compartir
- [ ] Pegar el link https://seasonpay.vercel.app/hola en un chat de WhatsApp o en un post de Facebook (sin publicar): debe salir la imagen azul con "Tu temporada en EE. UU., con los números claros".
  - Si Facebook muestra una imagen vieja, pásalo por https://developers.facebook.com/tools/debug/ y toca "Volver a extraer".
